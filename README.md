# Elysium Resort

Elysium Resort is a fictional resort nestled in the picturesque Maldives, offering a haven of tranquility where every moment is crafted to inspire relaxation. I created this personal portfolio project to test my skills in JavaScript and web design. Feel free to explore, and I hope you like it!

---

## Stand Out Features

- **Modal System**  
  This website features a basic modal system. Instead of each room having a dedicated page, I used modals to save space and loading time. The modals display nearby locations, activities, and individual room options at the resort.

- **Accordion**  
  With a little help from Stack Overflow, I implemented a fully functioning accordion that automatically closes when you open another question in the accordion.

- **On-scroll JavaScript Animations**  
  I explored on-scroll JavaScript animations to create smooth sliding-in effects, making the page more dynamic and engaging to navigate.

- **Navbar that Appears When Scrolling Up**  
  I’m quite proud of how smoothly this feature works. The navbar only appears when the user scrolls up, providing links for navigation. It disappears when the user scrolls down again.

- **Form Validation**  
  I implemented a form validation system to ensure that users are inputting correct information and filling out the necessary fields before submitting the form.

---

## Things to Be Aware Of

1. This is just a demo website. The resort is not a real place; it's simply a showcase of my current skills.
2. The "See All Villas" and "Book a Villa Now" buttons are identical and lead to the same section on the website.
3. The language selector and social links are just text placeholders; they do not lead anywhere when clicked.
4. The "Book Now" and "Get Directions" buttons do not work.
5. The video on the website is of very low quality to save space and loading time.
